## Design direction

- **Design Movement:** Dark modernist information design for high-stakes daily casework, with a distinctive product-tool personality instead of a conventional government portal or generic SaaS dashboard.
- **Core Principles:** state before spectacle; warm, intentional depth with dense records kept opaque and legible; every update is tied to canonical case history; accessible theme and motion controls are part of the product, not decorative extras.
- **Color Philosophy:** Dark-first charcoal/near-black rather than blue enterprise chrome; high-contrast warm white text and secondary greys; vivid orange `#FF4D00` for selected/active/primary coordination states only; warm amber/red/green reserved for semantic time pressure, severity and success. Light mode uses its own warm off-white and bright surfaces while sharing the same orange identity.
- **Dark tokens:** `#0B0B0C` background, `#111112` secondary, `#181819` elevated, `#202021` hover, `#FF4D00` primary accent, `#FF6A2A` secondary accent, `rgba(255,77,0,.20)` limited selected glow, `#F5F5F5` primary text, `#929299` secondary text, `rgba(255,255,255,.10)` borders and `rgba(255,255,255,.07)` glass highlight. Never use blue/cyan as dark-mode primary accent; no blue/cyan glow, purple gradients or full-screen animated glow.
- **Light tokens:** warm off-white page background, white/warm elevated surfaces, charcoal text, neutral fine borders, muted grey metadata, restrained warm shadows, and the same orange accent. Maintain contrast for charts, tooltips, modals, forms, tables, badges, and popovers in both themes.
- **Layout Paradigm:** Keep the existing persistent navigation/content relationship and reliable dense registry tables. Upgrade the sidebar and top toolbar as subtle warm translucent glass, place compact overview KPIs and coordination/live activity above readable opaque chart/table surfaces, and layer glass selectively for menus, overlays, and relationship showcase panels. Preserve existing routes and avoid a marketing hero.
- **Signature Elements:** a recognizable editable non-official case-record mark; a restrained orange active marker; a real-time case activity/timeline trace connecting institution and records.
- **Interaction Philosophy:** trust comes from predictable actions, visible source records, explainable match signals and explicit demo boundaries. Keep frequent search, filtering, keyboard actions and records immediately responsive. Animate selected/occasional state changes for feedback or spatial continuity. Consequential actions remain explicitly confirmed and only show success after local state updates.
- **Animation:** Use the verified Motion-for-React API for layout/presence/shared elements only when continuity serves a task; CSS transitions for frequent simple press/hover states; Recharts animation only on meaningful state changes; no endless page or data loop. Initial entry, new activity/overlap, theme change, occasional dialogs, selected case/timeline transitions are suitable. Use short custom ease-out entry curves and restrained durations; no `scale(0)`, `ease-in`, `transition: all`, expensive layout animation under repeated updates, unnecessary blur, blocked keyboard navigation, or animation-on-typing. Treat the brief's desired choreography as purposeful, not constant. Respect `prefers-reduced-motion` (gentler but understandable states) and gate hover-only motion to fine pointers. See the verified components memo for exact source/API decisions and audit references.
- **Typography System:** retain high-legibility sans serif UI typography, strong contrast, tabular numerals for changing metrics, wrap institution names where identification depends on full text, and keep dense record detail readable across themes.
- **Brand Essence:** the shared institutional casework instrument that makes multi-Bureau context, timely action and human-reviewed relationships immediately visible; **precise, calm, distinctive**.
- **Brand Voice:** concise, operational and transparent about simulation. Examples: “Live demo · Synthetic events · Local only.” “Potential relationship — verify before coordinating.”
- **Wordmark & Logo:** retain the current editable, non-official stacked-record mark and concise case-monitoring wordmark; no fabricated government seals or NoteGo brand assets.
- **Signature Brand Color:** vivid warm orange `#FF4D00`, used sparingly and intentionally.
