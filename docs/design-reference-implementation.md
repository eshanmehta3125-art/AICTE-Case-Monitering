# Design reference implementation decisions

**Target:** the existing AICTE Integrated Case Monitoring dashboard. The official documentation, source examples, licensing and selected interactive demonstrations were inspected during the upgrade. The implementation retained the existing dependency set; it did not install a second motion engine or import vendor dashboard templates.

The app uses React 19, TypeScript, Tailwind v4, Wouter, the installed Framer Motion/Motion-compatible package, Recharts 2.15, Radix, Sonner and Lucide. Motion decisions are made against those installed APIs, rather than copying examples that import another `motion/react` package surface. All numeric/chart/feed values come from the shared fictional case state; synthetic activity is not represented as live AICTE data.

## Additional component explorations

Eight further official Aceternity and Magic UI examples—Animated Modal, Card Spotlight, Animated Tabs, Background Beams, Stateful Button, Animated Sidebar, Animated Beam and Progressive Blur—were inspected separately. The actual demos, API/dependency confidence, licensing status, accessibility/performance caveats and casework-specific use/exclusion decisions are documented in [`extra-component-exploration.md`](extra-component-exploration.md). The exact requested Aceternity Animated Sidebar page returned 404; the inspection did not substitute a differently named sidebar. Aceternity copyable source is not used where the exact component terms/API were unverified. Decorative spotlight, background beams, blur overlays and a second accessible-component library were excluded from the dense casework product.

## SIH presentation additions

Guide Mode and Judge Mode are project-authored pages, not third-party dashboard components. The persistent `GuidedTourOverlay` carries a six-step position in URL query state while opening the actual existing synthetic Overview, Institution 360°, case detail, Overlap Review, Workload and Reports routes. Judge Mode provides a 4:15 runbook and explicitly separates implemented browser-local behavior from conceptual, unconnected production layers. The pages do not add dependencies, a backend, authentication or live API calls.

The institution-to-case relationship uses native SVG `markerEnd` arrowheads and the already-installed Framer Motion API for a slow, low-amplitude opacity/stroke-width breathing loop on shared-identity records. The path has `pointer-events: none`; linked institution/case cards remain the actual interactive targets. `useReducedMotion` renders the connector in a stable, static state; name-variation candidates remain unconnected. The route Suspense fallback uses shared `--canvas`, `--ink-soft` and `--orange-bright` tokens so the selected Dark/Light/System palette is preserved while a lazy route loads. No additional source component or vendor license was introduced for these refinements.
